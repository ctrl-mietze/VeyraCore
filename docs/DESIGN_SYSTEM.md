# VeyraCore · Visual Design System

Independent visual identity for the Android app (`ctrl.veyracore`).

- Canvas: `#000000` (real AMOLED black).
- Elevated card: `#0B0A0F`.
- Raised surface: `#17141E`.
- Primary: `#A855F7`.
- Accent: `#D2A6FF`.
- Main text: `#F8F5FB`.

## Application rules
- Keep one adaptive floral app icon and the established Veyra vocabulary.
- Do not replace important status labels with color alone.
- Navigation always includes Home, Options and Logs.
- Show Modules and Superuser only with a current verified UID-0 result.
- Certificates, system UID 1000, detected external apps, or a completed UI checklist cannot substitute for a UID-0 proof.
- Root and driver options require an exact, validated device/firmware/kernel profile. Unsupported is a real state, not an error to be painted green.

## Visual references
Derived from the existing Veyra Root Material color palette and the Raspberry Manager pink/violet charcoal theme; UI code is original for VeyraCore.
